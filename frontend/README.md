# DevNixEdu — Parent Dashboard (Frontend Only)

A frontend-only implementation of Mohsin Ali's assigned Parent Dashboard module from the DevNixEdu project documentation.

## Tech stack
- Next.js App Router
- React
- Tailwind CSS
- Lucide React icons
- Local mock/demo data (no backend or database)

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

## Included
- Parent dashboard overview
- Multi-child selector
- Child summary cards
- Child attendance page with search and status filters
- Child fees page with month/status filters and demo payment interaction
- Responsive sidebar and mobile navigation
- Profile dropdown and notifications panel
- Mock data in `src/data/parentDemoData.js`

## Important
This is a frontend demo. Authentication, persistent payments, live school records, APIs, and database connectivity are intentionally not implemented. Demo interactions are held in browser UI state only.
